# FinTrack v0.2.0

## Highlights

- Faster phone-first Home and Activity workflows, amount-first transaction entry,
  shared-account goal allocations, and clearer policy forms.
- Interactive cash-flow, net-worth composition and loan-balance comparisons, with
  exact financial values and accessible alternatives.
- Loan payments, investment activity and insurance premiums can create a linked
  cash entry or match an existing bank transaction without posting money twice.
- Recurring occurrences can be posted or matched. Forecasts include recorded loan
  EMIs, insurance premiums and confirmed deposit payouts, with duplicate-review
  warnings rather than unreliable totals.
- Partial receivable settlement, receipt-period expense reimbursements, and
  fixed-deposit maturity/interest tracking.
- Loan-overpayment protection, partial-EMI handling, atomic financial changes,
  guarded undo, and import reconciliation safeguards.
- Improved saved-backup verification and keyboard accessibility.

## Before updating

1. Export a complete encrypted `.finapp` backup and reopen the saved file to
   verify it. Keep the file and its PIN somewhere separate from the app.
2. Download the **APK**, verify it against `SHA256SUMS`, and install it over the
   existing production app. Do not uninstall or clear app data during an update.
3. Unlock with the existing app PIN, review your records, and create a new
   verified backup after the update.

This release keeps the production package and signing identity used for the
signed v0.1.0 build. Old debug APKs signed with a different key cannot be upgraded
in place; follow the backup-and-restore instructions in the release policy.

Data schema **v3** adds linked financial-event history and deposit terms.
Existing v1/v2 data and backups remain readable. Older app builds cannot restore
new v3 backups; retain your pre-update backup if you need recovery options.
Existing transactions are not retroactively converted into linked cash entries.
Legacy ambiguous goal funding and possible duplicate schedules require review.

## Artifacts and scope

- `FinTrack-0.2.0.apk`: signed Android installer.
- `FinTrack-0.2.0.aab`: signed Android App Bundle; not a sideload installer.
- `FinTrack-0.2.0.cdx.json`: CycloneDX software bill of materials.
- `SHA256SUMS`: checksums for the release artifacts.

Android version name: `0.2.0`; version code: `2000`.

FinTrack remains offline and single-user. Bank entries, market prices and contract
terms are user-provided. Calculators are illustrations, not financial advice.
Updates are installed externally; the app does not download APK updates or sync
household data. Android system backup still excludes document attachments, so a
complete manual backup remains necessary.
